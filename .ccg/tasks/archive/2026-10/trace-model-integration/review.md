## Findings 与处理

| 问题 | 处理 | 核验 |
| --- | --- | --- |
| 模型与检索授权可能互相替代 | Engine 在创建运行前按声明区分 modelConsent 与 dataConsent | 临时数据库核对两个缺失授权方向均拒绝；未改正式数据库 |
| 替换原导出插件会影响历史装配或审批 | 新建 trace.model.archive，委托原实现 | 原 trace-archive-export 与 trace-case-intake 无差异；原等待审批保留 |
| 同一网页用于多条事实时引用覆盖 | 引用键使用 factId:pageId；事实和关系轮询保留材料 | 纯投影核对多事实同页摘录并存 |
| 仅复核子事实却暗示完整问题成立 | 上下文纳入原始问题和完整调查主张 | 直接点验 claims 和实际送入证据 |
| 未记录最终跳转地址却称原始出处 | 上下文明确“最终跳转地址未记录，原始出处待人工核对” | 下载 JSON 引用包含边界说明 |
| 无真实完成依据的模型意见可能被导出 | 新档案插件从持久步骤状态确认 model.verify completed | 实际完成运行、模型记录及档案 modelReview 一致 |
| 后续新证据错误沿用旧模型意见 | 前端按完成时间与所看版本判断过期；后续导出不带旧意见 | 核对 stale 仅在 completed 时生效及 revision 条件 |
| 取消或拒绝显示为仍执行/可交付 | Case 补终态，ModelReview 区分未开始与已开始取消 | 局部静态渲染核验取消文案；机械修正已自行验证，无需复审 |
