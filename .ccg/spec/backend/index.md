# 本机Runtime约定

- Registry定义精确版本与协议Schema；能力扩展使用受信任本地插件，不在Engine增加能力ID分支。
- 运行持久化不可变清单、权限与项目revision。执行及重试核对已确认项目版本。
- 审批绑定输入哈希，默认逐步骤。显式同approvalScope才能共享交付确认，外部写始终逐步骤确认。
- ctx模型/文件操作核对能力声明、运行权限和本次资料授权；取消后拒绝晚到上下文调用。
- shutdown先停止工作并等待受控Provider/文件清理，再关闭SQLite。
- 运行完成且文件摘要匹配才允许下载；未登记或失败任务文件不得作为正式交付。
- 无模型配置就是不可用，不以规则或样例输出充当AI成功。

- 导出发生于run.completed之前；执行中快照必须标注时点，最终凭证仅在完成后核对完成事件/审批/export事件/文件摘要生成，禁止重写历史快照冒充最终状态。

- 历史代码迁移须冻结原commit/文件摘要并明确许可事实；跨文件算法的迁移摘要须进入插件manifest/Registry实现摘要，不把设计参考标为代码迁移。来源摘要不是自动同步的上游当前摘要。
- 上传资料的JSON解析依据filename扩展名；保留.json再核验结构，不能把默认.txt中的JSON文本误当成已经解析的多资料bundle。

- TRACE数量判断绑定原句的主体、地区、指标、年份/期间及单位；约数不证明严格门槛，年度报告不借用月度或上年数字。不同统计来源分别保留，口径差异不等于同口径直接矛盾；规则更新后另存档案版本。

- TRACE 当前评估与冻结档案按判断及关键证据内容指纹比较；规则版本更新不能重写旧档案。维护重算须限定明确运行ID并校验旧文件摘要。
- SearchPro 每次实际HTTP请求（含重试）先占预算；原文读取不扣搜索预算。范围拒绝须在任何外发搜索或模型调用前执行。
- 页面详情可提供移除重复正文的展示视图，但不得改变存储、默认完整读取、证据判断或档案内容。
