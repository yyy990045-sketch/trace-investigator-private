## 进阶演示说明（对应赛题「深度调查」）

`r3-deep.mp4` 与同名截图记录的是同一条调查的完整链路：

1. 首次提问 → 检索 → 结论「存在争议」（`r3-deep-2-first-verdict.png`）
2. 自己判断材料不够 → 追加一次检索，换成更具体的说法（`r3-deep-3-second-query.png`）
3. 重算后结论与来源变化（`r3-deep-4-after-second-round.png`）
4. 人工确认（`r3-deep-5-approved.png`）
5. 生成调查档案页，含证据链与未核实项（`r3-deep-6-archive.png`，HTTP 200）

## 提交时怎么讲

- **搜索是必需项**：三次查询的结论页都带原文片段与可点开的来源；把搜索去掉，页面只剩「查不到」。
- **不装懂**：第 1、3 条都没有硬给结论（一个说证据不足并给最接近候选，一个说存在争议），第 2 条给了反证。
- **可复核**：每条都能点进原始页面核对，档案页把用过的来源与限制写在一起。
