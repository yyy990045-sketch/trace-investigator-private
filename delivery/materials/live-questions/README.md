## 三份提问分别验证了什么

- **Q1**：只有模糊情节时，系统会核线索、给候选，但证据不够就明说「证据不足」，不硬定案；资料里年份有分歧时按原句并列，不替任何一方下结论。
- **Q2**：日期角色区分——「通过」不等于「施行」。同一句话被判为**存在反证**，并给出相反的来源。
- **Q3**：实体型问句从「只会说证据不足」变成「读到原句就回答」，答案绑定原句、来源、发布页与限制；
  这次材料里同时出现支持与相反表述，所以规则层仍写「存在相互矛盾的说法」——回答与「已核实」是两件事，页面没有把二者混为一谈。

## 录制中发现的一个真实缺陷（未修，先记录）

同一句话改用问句形式提交时结论会变：

```
《个人信息保护法》是不是 2021 年 8 月 20 日开始施行的？   →  页面结论：有依据支持（错误）
《个人信息保护法》自2021年8月20日起施行                  →  页面结论：存在反证（正确）
```

运行 ID：`run_9131f5b1-6774-44f8-817c-0d6dea254f25`（问句形式，判为 supported）。
根因方向：「是不是…？」被改写成陈述句后，日期角色判定没有生效，把「通过日」当成了「施行日」。
这条已如实记录，未在本次交付里修改判定逻辑；Q2 的录屏因此使用陈述句形式（该形式结论正确）。
