# 陌生用户体验方案（P2，待真实参与者）

本文件是执行工具，不是结果。**当前没有任何陌生人完成过体验，因此不能声称已经验证。**

## 招募与告知

- 建议 5 位未参与开发、也未看过本项目演示的人；由项目负责人邀请或使用其批准的渠道。
- 只告知一件事：「这是一个能自己上网查证说法的工具，你随便问一个自己真正想知道真假的说法。」
- 不预先解释怎么点、也不解释「证据不足」是什么意思；卡住后可以帮助，但必须计数。
- 征得同意后再截图或引用原话；不记录不必要的真实姓名、联系方式与敏感提问内容。

## 每人任务（三步，全程只做一次）

1. 提出一个自己真正想核实的说法，完成一次调查，并说出「它到底答了什么」。
2. 打开页面上的原始来源，判断这个来源是否支持页面上的说法。
3. 返回首页再回到这次调查记录，确认记录还在、内容一致。

## 记录表（每次体验一行，匿名编号）

| 字段 | 说明 |
|---|---|
| 编号 | U1…U5，不与真实身份关联 |
| 版本 | 部署提交 SHA 或日期 |
| 问题 | 用户自己提出的原话（如需脱敏由用户确认） |
| run_id | 本次调查的真实运行 ID |
| 结果 | 独立完成 / 指导后完成 / 放弃 |
| 提示次数与位置 | 例如「1 次，在提交后不知道要等多久」 |
| 时长 | 从开始提问到看完记录 |
| 是否打开来源 | 是 / 否，以及是否说得出这份来源能证明什么 |
| 是否区分「来源说法」与「已核实」 | 是 / 否，记录原话 |
| 可复现问题 | 现象 + 复现步骤 |

## 判定口径

- **独立完成**：不需要任何提示就走完三步。
- **指导后完成**：需要提示，记录提示内容；这类不计入独立完成。
- **放弃**：中途停止，记录停在哪一步。
- 汇总时同时保留正面与负面反馈；负面反馈不解释成用户不会用，正面反馈也不当作能力证明。
- 样本量为 5，只能作为下一轮改进依据；不宣称准确率、留存或竞争力结论。

## 中途失败怎么记

体验中若失败、卡住或放弃，**不要为了能提交反馈而硬把调查做完**。直接在记录表里记下现象与 run_id；这些记录同样有效。运行反馈接口只接受已结束的调查，因此未结束的情况以本表为准。

## 交付形态说明（2026-10-25 决定）

- 公网入口按项目负责人决定，直接使用服务器端口：`http://134.175.111.217:8090`，不做域名与 HTTPS。
- 原因有实测证据：该主机对未备案域名的请求会被云厂商拦截（`302 → dnspod.qcloud.com/static/webblock.html`），因此 Caddy 的自动证书拿不到；要上 HTTPS 只能走 Cloudflare 命名隧道或已备案域名，两者都需要额外的账号与备案条件。
- 影响：链路上的会话 Cookie 无法带 `Secure`；会话归属、每 IP 配额、同源校验与公开案例只读白名单仍然生效，但明文链路可被中间人观察。此风险已如实记录，不作为已解决项。
- 陌生用户体验（本文件前段）按同一决定不再组织；当前**没有任何真实陌生用户反馈**，不得据此宣称已获得用户验证。
