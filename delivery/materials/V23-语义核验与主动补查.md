# TRACE｜通用语义核验、缺口驱动补查与「答了一部分」（本轮实测）

## 改动

1. **新增说法语义层** `services/runtime/adapters/trace/claim-semantics.ts`
   把待核查说法拆成：主体 / 行为 / 对象 / 范围（型号·地区）/ 时间 / 限定（已经·计划·可能·部分）/ 关系性质（事实·相关·因果·预测），
   再与真实原句比较，输出五档：直接支持 / 直接反驳 / 只支持一部分 / 有关联但不足以证明 / 无关。
   三条硬约束写在判定里：**相关≠因果**、**单个型号停产≠整个系列**、**计划≠已发生**。
   只有带可识别谓词的说法（停产/延长寿命…）走语义层，法律日期与统计数字继续走原规则。

2. **缺口驱动的自动补查** `POST /v1/runs/:id/trace/auto`
   按真实缺口生成查询：只有摘要→先取原文；说法点了型号→查型号与系列的区别；因果/研究类→查研究结论；
   没有官方来源→查官方公告。每轮重算，拿到明确结论即停止，最多 2 轮。

3. **「答了一部分」**：新增 outcome `partial`。有支持性表述但缺原文/官方依据时，
   不再只回「证据不足」，而是先给「已经查清的部分（原文）」+「还缺什么」，并生成自然语言的直接回答。
   `partialAnswer` 在结果页第一屏展示。

## 实测

| 任务 | 结果 |
|---|---|
| B PS4 停产传言 | `partial`：「已经查到可直接引用的表述——百度百科：2021年,索尼确认将停产多个型号的PS4主机,仅保留基本的 PS4 Slim 500GB」+「还缺少官方原始页面」；自动补查了两轮（型号区别、官方公告） |
| C 咖啡与寿命 | 语义层把「媒体转述研究结论」判为部分支持，结论从 `supported` 降为 `insufficient/partial`，并在理由里写明「只支持其中一部分或只是相关」 |
| A 影视错误记忆 | `ambiguous` 最可能《解密》+《暗算》对照 + 主演名单里没有布拉德·皮特 |
