# TRACE｜V19 核心调查能力修复（实测记录）

## 已解决的四个根因

1. **候选召回不足** → 两阶段：第一阶段放宽发现（正文里「电视剧《X》」「X 是一部电影」也算名字；
   名字只出现一次但同句命中剧情线索也先收进来；上限 6 → 24；过滤科普/教程类假作品名；
   要求名字附近有「电影/上映/主演/导演…」等作品上下文）；第二阶段才做线索核对、类型比较与排序。
2. **作品类型/版本** → 从真实句子取类型证据（电影/电视剧/动画/小说），归并后与用户说法比较；
   电影 ≠ 电视剧，类型不符的候选仍保留但要标注矛盾、且不能成为「已找到」的答案；
   并列比较只与同类型候选进行。
3. **人物冲突误判** → 区分 `explicit`（资料有明确否定表述，才算反证）与 `absent`
   （只是现有资料的主演名单里没出现这个人，不能推断用户记错）；`absent` 不再阻断定案，
   只在结论里写「现有资料的主演名单里没有出现…（这不等于他没参演）」。
4. **补查方向被错误候选锁定** → `nextClueSearch` 按状态分支：类型矛盾先按用户类型重找候选；
   人物线索未命中先查演职员表；主演对上但剧情覆盖不足时去掉人名只用剧情再查；
   无候选时换关键词；已有答案立即停止。

## 三道真实问题（元宝 SearchPro 实搜）

**A 候选召回 + 类型 + 记忆冲突（主线）**
- 输入：有一部电影，讲一个数学天才在纸上推演密码，后来卷入间谍案，主角好像是布拉德·皮特演的
- 首轮：`insufficient`，提示「电影与电视剧对不上：《暗算》是电视剧」，候选含 暗算(tv)、解密(film)
- 自主补查：`数学 天才 推演 密码 卷入 电影`（按类型重找）→ 再 `模仿游戲 主演 演员表`
- 最终：**`found`：《模仿游戏》**，并注明「现有资料的主演名单里没有出现「布拉德·皮特」（这不等于他没参演）」
- 解密、暗算都进入了候选：解密(film, 1 条)、暗算(tv, 2 条，标类型矛盾)

**B 年份记错**
- 输入：男主角不停重复同一天，每次醒来都在一列火车上，最后发现是爆炸案，我记得是2005年上映的
- 年份已不再进主检索式（避免把正确作品筛掉）；当前结果：候选为《南来北往》等电视剧，
  系统给出「电影与电视剧对不上」，未硬给答案 → `insufficient`
- **未解决**：正确作品《源代码》(2011) 没有被召回，见「仍存在的问题」

**C 复杂剧情缺失**
- 输入：讲一个男人每天都能听见别人心里的想法，后来他遇到一个女孩却听不到她的心声
- 首轮 `ambiguous` → 自动换检索方向 → 仍 `ambiguous`，页面给出可补充的区分性线索
- **未解决**：候选里混入了非影视条目
