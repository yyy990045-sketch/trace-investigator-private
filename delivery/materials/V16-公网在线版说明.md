## 二、访问控制与资源限制（服务端强制，不在前端）

- **匿名会话**：打开页面自动领取会话令牌（HttpOnly Cookie + 请求头双通道），调查记录只属于该会话；换一个浏览器/会话读不到别人的记录（实测：跨会话访问返回「任务不存在」）。
- **配额**：
  - 每会话每天 **3 次**调查（实测第 4 次被拒，页面提示「这个会话今天已经发起 3 次调查，达到上限 3 次」）；
  - 每 IP 每天 **12 次**调查（同一出口 IP 多会话共享）；
  - 每会话同时只能有 **1 个**调查在跑；
  - 每个 IP 每小时最多领 **10 个**会话。
- **检索预算**：单次调查最多 **8 次**真实检索；全站每天 **300 次**检索、**100 次**调查，超限直接拒绝并提示，不会静默降级成假结果。
- **超时与取消**：单次调查最长 **5 分钟**，到点自动取消；页面提供取消入口，取消后状态如实记为已取消。
- **密钥**：元宝 SearchPro 与模型 Key 只存在于服务器容器环境变量里，前端产物经扫描不含任何密钥或本机路径。
- **可观测**：`GET /v1/admin/metrics`（需管理令牌）返回今日会话数、调查数、检索消耗、失败分布与平均时长。

## 四、系统说明

- 服务端：腾讯云 Ubuntu 22.04 主机，Docker Compose 运行 `trace-runtime`（Fastify + SQLite，持久卷 `/opt/trace/data`）与 `trace-web`（Caddy 托管前端并反代 `/api`）。
- 对外 HTTPS：该域名未在腾讯云备案，80/443 上的域名校验会被拦截，因此由 Cloudflare Tunnel（`cloudflared`）终止 TLS 并回源到本机 8081。
- **注意**：Cloudflare Tunnel 目前使用的是临时域名（`*.trycloudflare.com`），容器重启后地址会变化。长期对外请使用已备案域名（Caddy 可自动签发证书）或 Cloudflare 命名隧道。

## 五、已知限制（不隐瞒）

1. 问句会被改写成「可核查的说法」再检索（改写依据显示在调查页）；改写是规则式的，不做语义推理。
2. 检索式由规则扩展（多组数值各查一次 + 一条官方口径检索），不是模型规划；复杂问题仍可能漏检。
3. 归属判定从严：只有能对上「这条事实」的句子才计入，因此常见结果是「证据不足」而不是硬给结论。
4. 原文抓取受反爬/登录墙限制，取不到正文时只按摘要处理并在页面标注。
5. 会话按浏览器保存：清除浏览器数据会失去该会话的历史记录（记录仍在服务端，但无法再被该浏览器读到）。
