# UI V3：排版收紧记录

## 改了什么

1. **字号收敛到 6 级**：11 / 12 / 13.5 / 15 / 18 / 28（原 19 种散装字号）。做法是把 `ui.css` 与 `trace.css` 中 366 处 `font-size` 声明按就近原则映射到六级阶梯，`clamp()` 标题统一到 28px。
2. **统一 8px 间距阶梯**：4 / 8 / 12 / 16 / 24 / 32。`.trace-page` 只保留一档区块间距（24），主栏与侧栏内部 16；删掉了 44/51/52/75/121 这类一次性数值。
3. **案例页改双栏**：≥1200px 时 `.t-shell` = 主栏（待核查说法 → 结论 → 关键来源 → 证据）+ 320px 侧栏（事实分水岭、调查过程、版本、确认区、检索统计、技术细节），侧栏 sticky；<1200px 回退单列，顺序仍是先结论后过程。
4. **证据默认只展开 3 条来源**，其余进「展开其余 N 条相关来源」，内容一条不少。
5. **首页 hero 压缩**：标题、说明、输入框、示例入口挤进 531px，首屏同时看到输入框与 3 个示例入口；顺带把并行会话新增的「输入导入」一行压成紧凑条，功能保留。
6. 档案页与线索页沿用同一套间距与字号，不再单独出现散装字号。

| 案例页移动端总高 | 14231px | **7366px** | ≤9000px |

| 关键来源可见位置 | 首屏外 | **top=836px** | <900px |

## 可复现的验收方式

```bash
BASE=http://134.175.111.217:8090 \
CASE_ID=run_7ff5367b-1fbc-42e3-8f7c-0b8add9b9ab6 \
TRACE_CHROMIUM=<本机 Chromium 路径> node tooling/trace-ui-layout.mjs
```

16 条断言全部通过（字号级数、间距阶梯、总高上限、结论与关键来源位置、横向溢出）。`tooling/trace-ui-smoke.mjs` 加 `TRACE_LAYOUT_CHECK=1` 时会自动调用它。

## 取舍

- 双栏只用在案例页；档案页保持单列（它的阅读顺序是版本化档案，双栏会打断）。
- 证据默认展示 3 条是折叠而非删除：点开「展开其余 N 条」仍然是同一批来源。
- 首页输入框固定 72px（两行），再长的问题可以在展开后的输入区编辑。
