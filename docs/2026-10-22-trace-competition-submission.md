# 溯证 TRACE｜侦探赛道投稿说明

核对日期：2026-10-23。产品基线：a102c0f；本说明替换此前混用计数和版本的投稿草稿。

## 1. 可以直接使用的作品介绍

- 名称：溯证 TRACE
- 一句话：查清一句可疑说法的出处，分清原文、转载和证据缺口，把每次追问与修正留进可复查的调查档案。
- 适用用户：需要查证公开文字说法、比较网页来源的人。
- 使用方式：输入说法 → 确认事实和查询 → 元宝真实搜索 → 比较原文和来源 → 人工审阅 → 下载档案；可以继续追问并生成新版。
- 当前自动化边界：搜索、原文获取、规则关系判定、记录和导出真实执行；模型开关关闭，事实与语义仍需人工确认。不得写“AI 已完成语义核验”或“全自动深度调查”。
- 差异：搜索命中后继续检查证据；不能确认的地方明确保留；修正保留系统原判；新档案不覆盖旧版。
