## 7. 影响日常使用的剩余边界

1. 真实模型未配置，AI核验不可用；不能称AI验证完成。
2. 检索是词项匹配，事实规则是声明字面一致性，不能替代语义检索、事实真伪判断或专业审查；历史远端RAG未连接。
3. 仅支持UTF-8 txt/md/json，未支持PDF/OCR/Office；当前项目为本机单用户，确认人自述不是认证身份，不可直接公网多用户使用。
4. 已有待确认运行保持原样；代码实现变更后会受实现摘要门禁约束，需要重新核对并创建新运行，不能绕过门禁沿用旧批准。
5. 验收项目和失败记录为复现保留，长列表尚无分页；同一文件不同运行在资料模块会重复出现。装配仍是开发者使用的步骤/JSON配置，排序后配置区会折叠，需要重新展开。
